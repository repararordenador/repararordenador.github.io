REPORTE TÉCNICO: El problema de la "Edición N" en instalaciones Offline

Hemos comprobado en pruebas reales que al usar el Selector Universal (sin definir EditionID) en una instalación sin conexión a internet, Windows tiende a instalar por defecto la versión Windows 11 Pro N.

Esto sucede porque el instalador, al no poder validar la región online, elige el último índice de la lista Pro. Las versiones N no incluyen códecs multimedia (fallan apps como Cámara o WhatsApp). Para evitar esto, usa la opción "Forzar Windows Pro" que incluye la etiqueta Professional.

Guía de Configuración ei.cfg (Edición 2026)

El archivo ei.cfg es la herramienta definitiva para administradores que necesitan saltarse la restricción de la BIOS/UEFI que obliga a instalar Windows Home en equipos comprados con licencia de fábrica.

Truco Pro: Si ya instalaste la versión N por error, puedes descargar el "Media Feature Pack" desde Configuración > Características opcionales para recuperar los códecs, pero la clave Pro normal no te servirá para activarlo.

Estructura del archivo

Para crear el archivo correctamente, usa el Bloc de Notas y asegúrate de que el nombre sea exactamente ei.cfg (sin el .txt al final):

  • [EditionID]: Define si quieres Professional o Core.
  • [Channel]: Usa Retail para licencias estándar.
  • [VL]: 0 para usuarios normales, 1 para empresas.

Preguntas Frecuentes / Terminal Knowledge Base

Es un archivo de configuración basado en texto plano que se coloca manualmente dentro de la carpeta \sources\ de tu medio de instalación USB de Windows. Su función principal es anular los datos de la tabla ACPI MSDM de la placa base, permitiéndote omitir la clave de producto por defecto y forzar el menú de selección de arquitectura o ediciones.

Muchos usuarios descubren que al dejar el selector de edición libre, terminan con una versión de Windows llamada "Pro N". Esto es especialmente común cuando se instala Windows sin cable de red y sin Wi-Fi. La razón técnica es que el archivo install.wim contiene múltiples índices, y sin instrucciones precisas ni conexión, el motor de despliegue elige la variante europea "N" por orden jerárquico.

Sucede porque el instalador offline de Microsoft procesa las listas en orden alfabético/estructural inverso si no hay conexión para geolocalizar el equipo. Las versiones N carecen del software Windows Media Player y códecs de sistema. La forma definitiva de evitarlo es usando nuestra opción "Forzar Windows Pro" que prescribe el parámetro estricto Professional.

El archivo debe guardarse obligatoriamente en el directorio \sources\ de la unidad USB booteable que contiene el instalador de Windows (por ejemplo, E:\sources\ei.cfg). Si guardas el archivo en la raíz del pendrive, el asistente de instalación lo ignorará por completo.

El canal Retail está destinado a las licencias comerciales estándar, adquiridas en tiendas o licencias digitales OEM pregrabadas en fábrica. El canal Volume (VL) está diseñado para despliegues empresariales que validan sus sistemas de forma masiva a través de servidores de activación corporativos KMS o mediante claves múltiples MAK.

Si el Bloc de notas le añade la extensión oculta .txt, el sistema de instalación no reconocerá sus instrucciones y seguirá leyendo la clave Home predeterminada de la placa base. Para solucionarlo, debes activar la casilla "Extensiones de nombre de archivo" en la pestaña Vista del Explorador de Windows y renombrar el archivo eliminando el .txt sobrante.
