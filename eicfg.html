REPORTE TÉCNICO: El problema de la "Edición N" en instalaciones Offline

Hemos comprobado en pruebas reales que al usar el Selector Universal (sin definir EditionID) en una instalación sin conexión a internet, Windows tiende a instalar por defecto la versión Windows 11 Pro N.

Esto sucede porque el instalador, al no poder validar la región online, elige el último índice de la lista Pro. Las versiones N no incluyen códecs multimedia (fallan apps como Cámara o WhatsApp). Para evitar esto, usa la opción "Forzar Windows Pro" que incluye la etiqueta Professional.

Guía de Configuración ei.cfg (Edición 2026)

El archivo ei.cfg es la herramienta definitiva para administradores que necesitan saltarse la restricción de la BIOS/UEFI que obliga a instalar Windows Home en equipos comprados con licencia de fábrica.

Por qué falla el Selector en instalaciones Offline

Muchos usuarios descubren que al dejar el selector libre, terminan con una versión de Windows llamada "Pro N". Esto es especialmente común cuando se instala Windows sin cable de red y sin Wi-Fi. La razón técnica es que el archivo install.wim contiene múltiples índices, y sin instrucciones precisas ni conexión, el motor de despliegue elige la variante europea "N" por orden jerárquico.

Truco Pro: Si ya instalaste la versión N por error, puedes descargar el "Media Feature Pack" desde Configuración > Características opcionales para recuperar los códecs, pero la clave Pro normal no te servirá para activarlo.

Estructura del archivo

Para crear el archivo correctamente, usa el Bloc de Notas y asegúrate de que el nombre sea exactamente ei.cfg (sin el .txt al final):

  • [EditionID]: Define si quieres Professional o Core.
  • [Channel]: Usa Retail para licencias estándar.
  • [VL]: 0 para usuarios normales, 1 para empresas.
